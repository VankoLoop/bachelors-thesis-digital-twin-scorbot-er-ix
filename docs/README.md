# Reference documentation

The thesis relies on the original manufacturer documentation for the SCORBOT ER-IX and ACL Controller-B.
These manuals are copyrighted by Eshed Robotec / Intelitek, so they are **not redistributed** in this repository.
They are cited in the thesis bibliography as:

| # in thesis | Document | Local file name |
|---|---|---|
| [1] | *SCORBOT-ER IX User's Manual*, Catalog #100066 Rev. B, Eshed Robotec (Intelitek), 1999 | `SCORBOT_ER_IX.pdf` |
| [2] | *Controller-B User's Manual*, ACL Version 2.28, Catalog #100065 Rev. C, Intelitek Inc., 1995 | `CONTROLLER-B.pdf` |
| [3] | *ACL – Advanced Control Language, Reference Guide for Controller-B*, Eshed Robotec, 1995 | `ACL_B.pdf` |
| [5] | *ATS – Advanced Terminal Software User's Manual*, Eshed Robotec, 1995 | `ATS_B.pdf` |

If you have access to a SCORBOT lab, these manuals usually ship with the robot or can be requested from Intelitek.
Place them in this folder under the file names above. They are git-ignored.
